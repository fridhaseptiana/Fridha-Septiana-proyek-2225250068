## Judul Proyek
Program Pengolahan dan Analisis Data Nilai Mahasiswa

## Deskripsi Proyek
Proyek ini merupakan pengembangan dari proyek Pertemuan 14, yaitu Program Pengolahan dan Analisis Data Nilai Mahasiswa. Program dibuat untuk membaca data mahasiswa, mengolah nilai, menghitung rata-rata, menentukan nilai tertinggi dan terendah, serta menghitung jumlah mahasiswa yang lulus dan tidak lulus.

Pada Pertemuan 15, proyek dikembangkan dengan menerapkan modularisasi Python agar program lebih terstruktur, mudah dipahami, dan mudah diuji.

## Tujuan
1. Mengembangkan program dari Pertemuan 14.
2. Memisahkan program menjadi beberapa modul sesuai fungsinya.
3. Mengolah dan menganalisis data nilai mahasiswa.
4. Melakukan pengujian untuk memastikan program berjalan dengan benar.
5. Memperbaiki kesalahan yang ditemukan selama proses pengujian.

## Fitur Program
1. Membaca data mahasiswa dari file.
2. Memvalidasi data mahasiswa.
3. Menghitung rata-rata nilai mahasiswa.
4. Menentukan nilai tertinggi dan terendah.
5. Menghitung jumlah mahasiswa yang lulus dan tidak lulus.
6. Menampilkan hasil analisis nilai mahasiswa.

## Struktur Program
- `main.py`: Menjalankan program utama.
- `src/__init__.py`: Menandai folder src sebagai package Python.
- `src/input_data.py`: Membaca dan memvalidasi data mahasiswa.
- `src/proses.py`: Mengolah dan menganalisis nilai mahasiswa.
- `src/output.py`: Menampilkan data dan hasil analisis.
- `data/contoh_data.txt`: Menyimpan data nilai mahasiswa.
- `tests/test_case.md`: Dokumentasi pengujian program.
- `docs/screenshot/`: Menyimpan dokumentasi tangkapan layar program.

## Cara Menjalankan Program
Jalankan perintah berikut melalui terminal:

`python main.py`

## Pengujian
Pengujian dilakukan untuk memastikan setiap bagian program berjalan sesuai dengan hasil yang diharapkan. Pengujian mencakup pembacaan data, validasi data, perhitungan nilai, dan penampilan hasil analisis.

## Kesimpulan
Melalui pengembangan proyek Pertemuan 15, program pengolahan dan analisis data nilai mahasiswa menjadi lebih terstruktur dengan penggunaan beberapa modul Python. Pengujian juga dilakukan untuk memastikan program dapat berjalan dengan baik dan menghasilkan perhitungan yang benar.
